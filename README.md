# 雙拾 · 从晨光到灯火

双十校园影像交互预览，包含一日四拾、主题影集、校园地图和照片查看器。

网站：https://S1monS1ck.github.io/shuangshi/

## 更新与部署

网页源码和图片位于 `pages-preview/`。修改后推送到 `main` 分支，GitHub Actions 会自动将此目录发布到 GitHub Pages。

仓库 Settings → Pages → Build and deployment → Source 使用 **GitHub Actions**。

此站点为静态预览：投稿表单只将文字草稿保存在当前浏览器，不会上传或公开投稿。部分照片仍为纯色占位。地图来源见 `pages-preview/MAP-SOURCES.md`。

本项目为学生校园影像计划，非学校官方网站。
